# Seguridad

## Versiones cubiertas

Mientras Voxelfold permanezca en pre-release, las correcciones de seguridad se aplican sobre la rama principal y se distribuyen en la siguiente compilación firmada.

## Comunicar una vulnerabilidad

Utiliza la opción privada «Report a vulnerability» de la pestaña Security del repositorio. No abras una incidencia pública ni adjuntes bases de datos, credenciales, archivos de Hytale o información personal.

Incluye:

- Versión de Voxelfold y versión de macOS.
- Impacto observado y condiciones necesarias.
- Pasos mínimos para reproducirlo.
- Evidencia redactada que no contenga secretos ni recursos restringidos.

Se confirmará la recepción, se evaluará el alcance y se coordinará la divulgación después de disponer de una corrección. No se garantiza una recompensa económica.

## Límites

La investigación debe realizarse sobre equipos, cuentas y datos propios. No se autoriza acceder a instalaciones ajenas, interrumpir servicios, extraer recursos restringidos ni publicar información que pueda perjudicar a otros usuarios.
